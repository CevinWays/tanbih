# Aset Play Store

Dibuat dengan menyusun ulang aset brand, bukan di-export mentah — supaya
proporsinya dikendalikan di sini, bukan diserahkan ke alat lain. Wordmark
sempat ketarik 69% di splash karena hal itu.

| Berkas | Ukuran | Dipakai untuk |
|---|---|---|
| `play_icon_512.png` | 512×512 | Ikon aplikasi di Play Store |
| `play_feature_1024x500.png` | 1024×500 | Feature graphic di halaman toko |

Keduanya memakai navy `#131C2E` dan gradient brand `#2DB1B3 → #7AC793`.
Mark di feature graphic ditaruh di atas lingkaran navy karena lonceng mint
nyaris hilang di atas gradient mint — sekaligus membuatnya terbaca sebagai
ikon yang sama dengan yang dicari orang di laci aplikasi.
